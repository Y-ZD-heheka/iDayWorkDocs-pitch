# 商业计划书 & 投资人PPT 检查清单

---

## ✅ 内容完整性检查

### 1. 执行摘要
- [ ] 公司名称和定位清晰
- [ ] 一句话价值主张明确
- [ ] 融资金额和用途清楚
- [ ] 核心亮点突出

### 2. 问题与机会
- [ ] 目标用户痛点明确
- [ ] 有数据支撑市场规模
- [ ] 问题真实存在且紧迫
- [ ] 现有解决方案不足说明

### 3. 解决方案
- [ ] 产品/服务描述清晰
- [ ] 核心功能突出
- [ ] 价值主张明确
- [ ] 有产品截图或Demo

### 4. 市场规模
- [ ] TAM/SAM/SOM定义清晰
- [ ] 有可靠数据来源
- [ ] 计算逻辑合理
- [ ] 市场趋势分析

### 5. 商业模式
- [ ] 收入来源明确
- [ ] 定价策略合理
- [ ] 单位经济模型健康
- [ ] 盈利路径清晰

### 6. 竞争分析
- [ ] 主要竞品列出
- [ ] 竞争优势明确
- [ ] 壁垒/护城河说明
- [ ] 差异化定位清晰

### 7. 市场策略
- [ ] 获客渠道明确
- [ ] 增长策略可行
- [ ] 获客成本合理
- [ ] 转化路径清晰

### 8. 团队介绍
- [ ] 核心团队背景
- [ ] 与项目相关经验
- [ ] 团队互补性
- [ ] 顾问/投资人背书

### 9. 财务预测
- [ ] 3-5年收入预测
- [ ] 成本结构清晰
- [ ] 关键指标健康
- [ ] 盈亏平衡时间

### 10. 融资需求
- [ ] 融资金额明确
- [ ] 出让股权合理
- [ ] 资金用途清晰
- [ ] 里程碑规划

- [ ] 层次分明

- [ ] 关键数据可视化
- [ ] 图表类型合适

## 📝 表达质量检查

### 语言表达
- [ ] 简洁明了
- [ ] 无错别字/语法错误
- [ ] 专业术语准确
- [ ] 逻辑连贯

### 故事线
- [ ] 开头吸引人
- [ ] 问题→方案→价值清晰
- [ ] 有具体案例/数据

## 🎯 投资人关注点

### 必须回答的问题
- [ ] 为什么是现在？
- [ ] 为什么是你们？
- [ ] 市场有多大？
- [ ] 怎么赚钱？
- [ ] 竞争壁垒是什么？
- [ ] 资金怎么用？
- [ ] 退出路径是什么？

### 常见扣分项
- [ ] 市场规模虚高
- [ ] 财务预测不切实际
- [ ] 竞争分析避重就轻
- [ ] 团队背景与项目不匹配
- [ ] 资金用途不清晰
